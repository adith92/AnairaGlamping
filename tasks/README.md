# Panduan Tugas AI Dev (Tasks Directory)

Selamat datang di folder `/tasks/` proyek **Anaira Glamping & Resort PMS & Booking Center**. Folder ini digunakan sebagai pusat pelacakan, perencanaan, dan status implementasi fitur-fitur baru.

## Aturan Alur Kerja AI (Workflow Rules)

Untuk menjaga konsistensi, keandalan, dan transparansi pengerjaan proyek oleh developer manusia maupun agen AI, ikuti aturan berikut tanpa kecuali:

1. **Semua Fitur Baru Harus Dimulai dari PRD:** Sebelum kode apa pun ditulis, PRD (Product Requirements Document) harus dibuat dan disimpan di folder ini dengan format nama `prd-[nama-fitur].md`.
2. **Setiap Implementasi Harus Mengikuti Checklist Tugas:** Setelah PRD disetujui, daftarkan seluruh sub-tugas yang detail dalam file tugas dengan format `tasks-[nama-fitur].md`.
3. **Pembaruan Status Tugas secara Realtime:** Setiap kali menyelesaikan sebuah sub-tugas, Anda **wajib** memperbarui statusnya dari `- [ ]` (belum selesai) menjadi `- [x]` (selesai). Jangan menandai tugas induk selesai sebelum seluruh sub-tugas di dalamnya selesai.
4. **Kerja Bertahap & Berurutan:** Kerjakan satu sub-tugas kecil dalam satu waktu. Lakukan pengujian dan validasi mandiri sebelum beralih ke sub-tugas berikutnya.

## Berkas yang Disimpan di Sini

- **`project-baseline.md`**: Dokumen baseline proyek yang mendeskripsikan teknologi, struktur folder, fitur yang ada, risiko, serta petunjuk menjalankan lokal.
- **`prd-[nama-fitur].md`**: Dokumen persyaratan produk untuk suatu fitur tertentu.
- **`tasks-[nama-fitur].md`**: Lembar kerja checklist tugas untuk panduan implementasi.
- **`master-ai-workflow.md`**: Panduan instruksi kerja bagi Agen AI untuk masa depan.
